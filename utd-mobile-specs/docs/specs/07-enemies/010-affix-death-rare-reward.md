# Death, Rare, Reward Affixes

Keep:
- Explosive: explodes on death.
- Splitting: splits into smaller enemies.
- Ancient: gains power over time.
- Void-Touched: changes armor type periodically.
- Ascendant: gains second affix at low HP.
- Titanic: massive HP increase, slower movement.
- Frenzied: below threshold gains speed burst.
- Rich: drops more gold and has more HP.
- Bountiful: drops more items/loot and has more HP.

Remove:
- Toxic
- Frostburst
- Temporal
- Mirror
