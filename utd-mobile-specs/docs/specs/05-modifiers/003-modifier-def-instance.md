# Modifier Def and Instance

ModifierDef fields:
- modifierDefId
- statId
- op
- value
- sourceType
- sourceId
- target
- stacking optional
- durationTicks optional
- tags optional

ModifierInstance fields:
- modifierInstanceId
- modifierDefId
- sourceEntityId/sourcePlayerId/sourceInstanceId optional
- targetEntityId/targetPlayerId optional
- appliedAtTick
- expiresAtTick optional
- valueOverride optional
