# Effect Parameters vs Stat IDs

Make something a StatId only if multiple systems may modify/read it.
Keep narrow one-off behavior as effect-specific param.

Effect-specific params:
- projectile arc height
- chain target selection style
- splash falloff curve type
- poison spread radius
- execute HP threshold
- trap trigger delay
- trap max trigger count
- beam tick interval
- split projectile angle
- tower-disable target count
- tower-disable selection rule
