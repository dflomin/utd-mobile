# Progression and Wave Commands

INVEST_ELEMENT:
- element FIRE|ICE|NATURE|LIGHT|DARK|MACHINE|UTILITY
- amount

USE_REROLL:
- reroll selection representing eligible recent drop rounds/drops

START_NEXT_WAVE:
- waveNumber

SET_SPEED:
- speedMultiplier 1|2|3

PAUSE_REQUEST / RESUME_REQUEST:
- optional reason
