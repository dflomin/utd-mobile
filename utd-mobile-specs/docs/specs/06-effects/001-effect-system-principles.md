# Effect System Principles

- Towers execute configured effect graphs.
- Effects are data definitions plus typed handlers.
- No bespoke tower classes.
- Curated hook/event registry.
- Hooks can mutate, cancel, replace, react.
- Deterministic numeric priority ordering.
- Max effect depth starts at 10.
- Loop detection required.
- No runtime scripting engine.
- No Phaser dependency in game-core.
