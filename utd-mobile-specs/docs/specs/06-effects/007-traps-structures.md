# Traps and Stationary Structures

Allowed:
- tower-generated traps
- stationary temporary turrets
- temporary aura totems
- mines
- persistent zones
- spell-created stationary structures

Not allowed:
- moving allied summons
- pathfinding minions
- pets
- player manually placing traps with touch coordinates

Placement is deterministic via tower ability logic. Spawned structures snapshot source stats at creation.
