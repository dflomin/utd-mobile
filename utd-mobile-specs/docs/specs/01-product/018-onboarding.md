# Onboarding

Use combination:
- guided first few runs
- progressive unlocks
- recommended beginner heroes/builds
- challenge/tutorial scenarios
- silent protection from punishing combos for first ~5 games

First 10 minutes of first run should feel easy, empowering, educational, curiosity-building, and curated.
First run can be capped intro showing elements, archetypes, potions, and items.
