# Reroll Model

- Rerolls apply only to tower blueprints.
- Default reroll window: last 3 drop rounds.
- Reroll window is runtime-configurable via hero/item/modifier effects.
- Reroll affects only unplaced blueprint drops from eligible recent rounds.
- Placed copies are excluded.
- Example: last 3 rounds produced 6 drops, player placed 1, reroll replaces remaining 5.
- Reroll uses separate currency.
- Reroll currency can recharge every 10 waves.
- Super rare mobs may drop reroll currency.
- Reroll-focused hero can start with more rerolls, recharge faster, and improve rarity odds.
