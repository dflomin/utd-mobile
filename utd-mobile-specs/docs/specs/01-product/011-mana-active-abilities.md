# Mana and Active Abilities

- Mana is per tower, not global.
- Only spell-casting towers use mana.
- More prevalent in Light/Dark but scattered across elements.
- Regen/max modified by heroes/items/potions.
- Active gameplay is limited.
- Players can toggle auto-cast per spell tower.
- Players can favorite 3 spells on field as always-visible buttons.
- Favorite spell casting triggers tower's configured targeting/effect, not arbitrary coordinates.
