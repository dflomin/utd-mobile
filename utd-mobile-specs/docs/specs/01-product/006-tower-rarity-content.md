# Tower Rarity Content

Per element target:
- 5 basic/common towers: simple representative mechanics.
- 5-7 rare towers: stronger baseline effects/stats.
- 5-7 super rare towers: more unique/extreme specialties.
- 6-8 epic towers: endgame carries or high-value utility/economy.

Every element should have 2-3 possible carry towers, mostly epic, some support-dependent and some less dependent.
