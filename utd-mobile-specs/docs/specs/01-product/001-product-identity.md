# Product Identity

Mobile-first landscape Android tower defense inspired by Warcraft 3 YouTD/UTD.

Core fantasy:
- elemental specialization
- weighted RNG tower discovery
- carry towers plus support synergies
- item and potion investment
- strategic interest/gold economy
- endless scaling where all runs eventually die
- strong post-run celebration and analytics

The game should feel like a systems-heavy roguelite TD, not a pure casual TD and not an RTS micro game.
