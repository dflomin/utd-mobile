# Modes, Maps, Pathing

Modes:
- Fast and long modes desired eventually.
- Modes are least core if something must be simplified.

Maps/pathing:
- No maze-building.
- Fixed lanes and locked build areas.
- Around 4 fundamentally similar maps with different layouts/textures.
- Solo: single clean lane.
- Multiplayer base map: two lanes start separately, then converge into central area accessible by both players.
