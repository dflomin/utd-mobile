# Mobile UI Rules

- Landscape orientation.
- Do not solve clutter by making everything tiny.
- Use contextual panels, collapsible groups, progressive disclosure, long-press details.

Always/high-priority visible:
- HP/lives
- gold
- wave/current wave
- upcoming wave indicator/pane
- element skill points
- favorite spells
- inventory button with tabs
- element investment button
- reroll count/access
- pause
- speed controls
- auto-start toggle
- multiplayer teammate status

Tower interaction:
- tap tower opens radial/context menu
- bottom/detail panel for deep stats/items/XP/targeting/aura/potions

Placement:
- tap empty build pad/slot, then choose buildable tower from inventory.
