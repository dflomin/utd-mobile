# Element Investment

- Each element has 15 investment levels.
- Element choices are permanent during a run.
- Towers from an element only enter the roll pool once the player has at least 1 point in that element.
- More investment increases that element's drop probability and rarity odds.
- Players may invest outside elements/utility to avoid polluting tower pool.
- Mobs can very rarely drop an item/resource that upgrades any element.
- Normal successful builds should max 2 elements, maybe 3 with lucky drops.
- Splashing utility elements is viable; moderate investment across many elements generally should not be optimal.
