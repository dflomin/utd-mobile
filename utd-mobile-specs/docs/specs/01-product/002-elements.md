# Elements

Target elements:
- Fire
- Ice
- Nature
- Light
- Dark
- Machine

Identity:
- Fire: damage-focused, splash/AOE bias.
- Ice: slow/control/AOE bias.
- Nature: jack-of-all-trades utility.
- Dark: DOTs, death, curses, draining, scaling.
- Light: chaining, mana/spell-oriented effects, supportive burst.
- Machine: economy, interest manipulation, late-game damage.

Every element should have a mix of roles, but each biases toward its identity.
