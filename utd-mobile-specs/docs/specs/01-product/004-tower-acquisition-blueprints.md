# Tower Acquisition and Blueprints

- Tower acquisition uses permanent blueprint inventory.
- After each wave, player receives random tower blueprints.
- Initial design: 3 blueprint drops per wave; may reduce to 2 later for fatigue.
- Blueprint copies stack.
- Stacked copies increase build capacity for that tower.
- Duplicate copies do not globally upgrade stats.
- Epic towers can only drop once.
- Common/rare towers become less prominent later.
- Weighted element specialization and inventory rules prevent long-run dilution.
