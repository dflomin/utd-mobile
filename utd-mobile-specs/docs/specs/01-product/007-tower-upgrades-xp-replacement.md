# Tower Upgrades, XP, Replacement

Upgrades:
- unlocked by elemental investment
- cost gold + upgrade points earned per wave
- transform tower into stronger version with different sprite
- mostly improve stats/existing effects; items define specialization

XP:
- kill participation grants XP
- killing blow grants more XP
- level cap 50

Replacement:
- tower may be replaced by same-element tower
- replacement inherits XP, items, and potion investment
- this encourages early commitment rather than hoarding for perfect carry
