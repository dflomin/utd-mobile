# First Build Target

Build vertical architecture, not content volume.

Implement first:
- monorepo scaffold
- game-core deterministic simulation
- command system
- content-config system
- modifier/stat skeleton
- effect hook skeleton
- blueprint inventory + reroll model
- basic combat loop
- simulator runner
- Phaser visual harness

Do not build multiplayer/monetization/large content first, but keep core multiplayer-ready.
