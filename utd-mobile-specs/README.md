# UTD Mobile Specs

This zip contains small, implementation-ready spec files for the Android Phaser tower defense project. Specs are intentionally split into many small files like Jira stories so AI/dev agents can consume them independently.

Read first:
- docs/specs/00-meta/000-agent-rules.md
- docs/specs/00-meta/001-spec-index.md
